## 每篇文档的结构

按以下顺序写，没有的部分可以省略。同一类算法有多篇时（如 psi.md 与 psi-oprf.md），共用的部分只写在一篇里，另一篇链接过去：

1. **概述**：解决什么问题，适用场景
2. **协议**：参与方、消息流程、数学原理、消息格式
3. **参数**：可选的曲线、哈希等，以及取值建议
4. **性能**：完整的测试数据和测试方法
5. **依据**：每个组件依据的标准或论文、类型（标准 / 论文 / 自定义）和验证方式
6. **安全性**：安全模型、泄露的信息、前提假设、使用注意
7. **接口**：各层入口的索引。具体用法写在对应语言绑定的文档里，这里不重复
8. **参考文献**

## 约定

- 文档描述的是已实现的行为。和代码不一致时以代码为准，并及时修正文档。
- 尚未实现的部分标注“规划中”或“待定”；没有实测的数字标注“未实测”或“估算”。
- 公式中的群运算用乘法记号（$H(x)^a$），有限域运算用加法记号。
